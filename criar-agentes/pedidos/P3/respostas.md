# Respostas às dúvidas do pedido P3

Respostas de quem fez o pedido. Copie para `respostas.md` quando o spec parar com dúvidas.

1. Uma tarefa está atrasada quando o prazo é anterior a hoje. Prazo igual a hoje não está atrasado.
2. Tarefas concluídas nunca estão atrasadas.
3. Tarefas sem prazo nunca estão atrasadas.
4. O resultado vem do prazo mais antigo para o mais recente. Prazos iguais mantêm a ordem da lista recebida.
5. Uma data de hoje fora do formato AAAA-MM-DD lança Error com a mensagem "Data inválida".
6. O resultado traz os próprios objetos recebidos, e a lista recebida não é alterada.
