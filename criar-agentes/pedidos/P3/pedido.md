# Pedido P3. Tarefas atrasadas

O time quer ver as tarefas atrasadas. O prazo e a data de hoje usam o formato AAAA-MM-DD.

Tipo: `Tarefa = { id: number, titulo: string, concluida: boolean, prazo?: string }`

Assinatura: `tarefasAtrasadas(tarefas: Tarefa[], hoje: string): Tarefa[]`

O código vai em `saida/tarefasAtrasadas.ts`, exportando a função `tarefasAtrasadas`.
