# Pedido E. Percentual concluído

O painel do time precisa mostrar quanto do trabalho da lista já está concluído.

Tipo: `Tarefa = { id: number, titulo: string, concluida: boolean }`

Assinatura: `percentualConcluido(tarefas: Tarefa[]): number`

O código vai em `saida/percentualConcluido.ts`, exportando a função `percentualConcluido`.
