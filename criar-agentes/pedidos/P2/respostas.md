# Respostas às dúvidas do pedido P2

Respostas de quem fez o pedido. Copie para `respostas.md` quando o spec parar com dúvidas.

1. A primeira página é a página 1.
2. Uma página depois do fim da lista retorna um array vazio, sem erro.
3. O tamanho precisa ser um número inteiro maior ou igual a 1. Fora disso, lança Error com a mensagem "Tamanho inválido".
4. A página precisa ser um número inteiro maior ou igual a 1. Fora disso, lança Error com a mensagem "Página inválida". Quando os dois são inválidos, vale a mensagem do tamanho.
5. A última página pode ter menos itens que o tamanho.
6. O resultado traz os próprios objetos recebidos, e a lista recebida não é alterada.
