# Pedido P2. Paginar tarefas

A tela de tarefas vai mostrar a lista em páginas de tamanho fixo.

Tipo: `Tarefa = { id: number, titulo: string, concluida: boolean }`

Assinatura: `paginarTarefas(tarefas: Tarefa[], pagina: number, tamanho: number): Tarefa[]`

O código vai em `saida/paginarTarefas.ts`, exportando a função `paginarTarefas`.
