# Pedido P7. Próximas tarefas

O time quer ver as tarefas que vencem nos próximos dias. O prazo e a data de hoje usam o formato AAAA-MM-DD.

Tipo: `Tarefa = { id: number, titulo: string, concluida: boolean, prazo?: string }`

Assinatura: `proximasTarefas(tarefas: Tarefa[], hoje: string, dias: number): Tarefa[]`

O código vai em `saida/proximasTarefas.ts`, exportando a função `proximasTarefas`.
