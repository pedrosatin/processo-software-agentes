# Respostas às dúvidas do pedido P1

Respostas de quem fez o pedido. Copie para `respostas.md` quando o spec parar com dúvidas.

1. A ordem das prioridades é alta, media e baixa.
2. Tarefas concluídas vão para o fim da lista, também ordenadas por prioridade entre si.
3. Tarefas com a mesma prioridade e o mesmo estado mantêm a ordem da lista recebida.
4. Uma prioridade fora das três lança Error com a mensagem "Prioridade inválida".
5. O resultado é um array novo com os próprios objetos recebidos, e a lista recebida não é alterada.
