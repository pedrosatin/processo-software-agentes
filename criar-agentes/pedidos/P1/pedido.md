# Pedido P1. Ordenar por prioridade

A lista do time deve aparecer com as tarefas mais importantes primeiro.

Tipo: `Tarefa = { id: number, titulo: string, concluida: boolean, prioridade: 'alta' | 'media' | 'baixa' }`

Assinatura: `ordenarPorPrioridade(tarefas: Tarefa[]): Tarefa[]`

O código vai em `saida/ordenarPorPrioridade.ts`, exportando a função `ordenarPorPrioridade`.
