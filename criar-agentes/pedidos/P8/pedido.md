# Pedido P8. Normalizar títulos

Os títulos importados de uma planilha antiga chegaram com espaços sobrando e letras minúsculas no começo.

Tipo: `Tarefa = { id: number, titulo: string, concluida: boolean }`

Assinatura: `normalizarTitulos(tarefas: Tarefa[]): Tarefa[]`

O código vai em `saida/normalizarTitulos.ts`, exportando a função `normalizarTitulos`.
