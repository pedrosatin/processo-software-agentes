# Respostas às dúvidas do pedido P8

Respostas de quem fez o pedido. Copie para `respostas.md` quando o spec parar com dúvidas.

1. Espaços no começo e no fim são removidos com trim().
2. Sequências de espaços, tabulações ou quebras de linha no meio viram um único espaço.
3. O primeiro caractere vira maiúsculo com toUpperCase(). O resto do título não muda.
4. Título vazio continua vazio.
5. O resultado traz cópias das tarefas, com os outros campos iguais. As tarefas recebidas não são alteradas.
6. O resultado segue a ordem da lista recebida.
