# Pedido P6. Buscar por tag

O time marca tarefas com tags e quer filtrar a lista por uma tag.

Tipo: `Tarefa = { id: number, titulo: string, concluida: boolean, tags: string[] }`

Assinatura: `buscarPorTag(tarefas: Tarefa[], tag: string): Tarefa[]`

O código vai em `saida/buscarPorTag.ts`, exportando a função `buscarPorTag`.
